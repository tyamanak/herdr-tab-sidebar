# 使い方

[English](usage.md) | 日本語

このページは、herdr-tab-sidebar の [README](../README.ja.md) の続きです。

## 動作要件

- Herdr 0.9.1 以降。開発とテストには Herdr 0.9.3 を使いました。
- Python 3.9 以降。Herdr サーバーの PATH 上で `python3` として見つかる必要があります。使うのは標準ライブラリだけです。`python3` がそれより古い場合は、すべてのフックとアクションが、その旨のメッセージを出して失敗します。
- macOS または Linux。以下の内容はすべて macOS で実行したものです。Linux では、まだ何も手で試していません。ユニットテストは、CI で Linux 上でも実行するように設定してあります。

## インストールは1つだけ

インストールは 1 つだけにしてください。別のプラグイン ID で 2 つ目を入れると（フォークや、インストール済みのものと並べてクローンをローカルで `herdr plugin link` した場合）、同じ `ts_*` トークンと、`config.toml` の同じ管理ブロックを書き込むことになり、互いの結果を打ち消し合います。

## 確認

```sh
herdr plugin action invoke tyamanak.tab-sidebar.status
herdr plugin log list --plugin tyamanak.tab-sidebar
```

`status` アクションが最後に出力した行は、`state: applied` か `state: released`、またはそのどちらかになるのを妨げているものです。アクションはバックグラウンドで動くので、その出力やエラーは、呼び出した端末ではなくプラグインログに残ります。

このリポジトリのクローンからは、同じ確認を、終了コードを返す 1 つのコマンドで行えます。

```sh
python3 main.py status --expect applied    # or: --expect released
```

`OK: applied (N rows)` か、`NOT applied:` とその理由を出力します。`python3 main.py preview` は、現在のセッションから作られる行を出力します。どちらも読み取りしか行いません。

## アクション

| アクション | 効果 |
|---|---|
| `tyamanak.tab-sidebar.apply` | 管理ブロックを `config.toml` に追加し、設定を再読み込みし、ビューを設定して、すべてのトークンを書き込む |
| `tyamanak.tab-sidebar.release` | ビューとすべてのトークンを消し、管理ブロックを取り除いて、設定を再読み込みする |
| `tyamanak.tab-sidebar.resync` | 現在のセッションをもとに、ビューとすべてのトークンを書き直す |
| `tyamanak.tab-sidebar.status` | 状態を報告する。何も変更しない |

一覧はセッションの変化にひとりでに追従し（ワークスペースの名前変更、タブの作成・クローズ・名前変更・移動、ペインのクローズ・移動、エージェントの検出とその状態の変化）、サーバーを再起動したあとも復元されます。`resync` は、それでも一覧が古いままに見えるときのためのものです。

## 更新

更新するには、もう一度インストールします。Herdr がチェックアウトを置き換えます。

```sh
herdr plugin install tyamanak/herdr-tab-sidebar
```

## 制限

- エージェントのいないタブは一覧に出ません。Herdr が一覧に出すのはエージェントが動いているペインだけなので、シェルしかないタブには行がありません。
- 状態アイコンは、行の先頭ではなく末尾にあります。Herdr は 1 つの項目の最初の行と、それに続く行とでインデントを変えるので、アイコンを先頭に置くと、ワークスペースの最初のタブとそれ以外のタブとで位置がそろいません。
- 適用中は、プラグインの一覧が、Herdr 自身による Agents パネルの並び順（`agent_panel_sort`）に取って代わります。`release` で元に戻ります。
- Herdr の Agent ビューは 1 つだけです。プラグインは実行のたびにこれを設定するので、別のプラグインが設定したビューを置き換えます。逆に、ビューを設定する別のプラグインは、このプラグインのビューを置き換えます。そのようなプラグインとの併用は試していません。
- 別のマシンのエージェント（Herdr は 1 つのクライアントに複数のマシンを表示できます）は、ローカルのグループの後ろに行が残りますが、その行に表示されるのはマシン名と状態アイコンだけです。行のレイアウトはすべての行に共通の 1 つの定義で、プラグインのトークンはローカルのペインにしか存在しないためです。これはコードとユニットテストの上での話で、実際のリモート接続では確かめていません。そのような使い方がほとんどであれば、先に `release` しておいてください。
- 複数のエージェントがいるタブのほかのエージェントには、プラグインの適用中、次/前のエージェントへの移動ではたどり着けません。
- Herdr が同時に実行するプラグインのコマンドは最大 32 個で、それを超えた分は捨てられます。非常に大きな変更が一度に起きて一覧が古いままになった場合は、次の変更か `resync` で直ります。
- 試していないこと: セッションを動かしたまま Herdr をその場で更新すること。単純なサーバーの再起動は、テストで確かめています（起動時フックが一覧を復元します）。
